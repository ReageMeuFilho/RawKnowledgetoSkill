## 1. Executive Summary

GuestWisely is a comprehensive, all-in-one Property Management System (PMS) engineered for professional short-term rental (STR) managers, agencies, boutique hotels, and individual property owners. The platform evolved from **365Villas**, a pioneering vacation rental software with over a decade of experience serving thousands of property managers across 60+ countries.

| Target Market | Core Value Proposition |
|---------------|------------------------|
| Professional property managers (20-500+ units), vacation rental agencies, boutique hotels | A unified, growth-focused, all-in-one platform that provides enterprise-grade power without complexity, backed by exceptional support |

## 3. Core Platform Modules

### 3.1 Channel Manager
- **60+ OTAs** supported (Airbnb Preferred Partner, Vrbo, Booking.com, Expedia)
- Real-time two-way sync (calendars, rates, content)
- Centralized calendar with source color-coding
- Channel-specific rate markups (fixed or %)
- Native, built-in module (not third-party)

### 3.2 Website & Booking Engine
- Professional templates (no coding required)
- Custom branding and domain
- Advanced property search (map-based, amenities, filters)
- WordPress plugin for existing sites
- Direct booking analytics

### 3.3 Reservation Manager
- Multi-property unified calendar
- Inquiry and quote management with automation
- Booking lifecycle automation (confirm, cancel, modify)
- Centralized guest profiles (CRM)
- Drag-and-drop functionality
- Error validation (double-booking prevention)

### 3.4 Unified Communication Hub
- Aggregated multi-channel inbox (Airbnb, Vrbo, Booking.com, email, SMS)
- Unified conversation threads per guest
- Automated messaging with triggers
- Smart templates with dynamic variables
- Internal team messaging (hidden from guest)
- **Quote Chaser** automation for unconverted quotes

### 3.5 Reports & Insights
- Customizable real-time dashboard
- Financial reporting (revenue, P&L, tax, expenses)
- Occupancy analytics (ADR, RevPAR, booking pace)
- Automated owner statements
- **Custom report builder**
- **Scheduled report delivery** (auto-email)

### 3.6 Integrated Accounting
- Automated invoicing and receipts
- Payment processing (deposits, balances, security deposits, refunds)
- **Trust accounting** (separate ledgers for owner/operational funds)
- Automated owner payouts
- Multi-currency and tax handling
- QuickBooks/Xero sync
