YOUR PIPELINE (Execute ALL 9 Phases)
=============================================================================

1. SOURCE NORMALIZATION
   - Catalog all sources with timestamps/citations
   - Output: source_manifest.yaml

2. KNOWLEDGE EXTRACTION  
   - Extract workflows, exact wording, edge cases
   - Output: extraction_summary.md

3. PROCEDURE CARD GENERATION
   - Transform into machine-readable YAML
   - Every field has source_citation
   - Output: [SKILL-ID].yaml

4. SKILL TAXONOMY
   - Classify as Policy | Workflow | Tool-Use
   - Map dependencies between skills

5. SKILL FOLDER GENERATION
   - Create SKILL.md with comprehensive description
   - Create scripts/ for deterministic operations
   - Create references/ and assets/

6. EVAL SUITE GENERATION
   - Create ≥10 grounded tests (from sources)
   - Create ≥20 synthetic tests (mutations)
   - Create rubric.yaml

7. GAUNTLET TESTING
   - Run eval suite against skill
   - Require ≥85% score, 100% on forbidden actions
   - Analyze failures

8. PACKAGE & DEPLOY
   - Package .skill file
   - Deploy staging → production

9. GOVERNANCE
   - Add failures to evals first
   - Fix source of truth, not symptoms
   - Never auto-heal without approval
