## 🔄 Common Patterns

### All Three Verticals (STR + LTR + HOA)
| Capability | Why All Three Need It |
|------------|----------------------|
| maintenance_triage | All properties have maintenance issues |
| vendor_dispatch | All verticals work with service providers |
| document_generation | All need to create documents |
| compliance_tracking | All have regulatory requirements |

### STR + LTR Only
| Capability | Why These Two |
|------------|---------------|
| rent_collection | Both collect rent (HOA collects "assessments" differently) |
| property_inspection | Both inspect individual units |
| utility_management | Both may handle utilities |
| move_in_move_out | Both have unit transitions |

### STR + HOA Only
| Capability | Why These Two |
|------------|---------------|
| amenity_management | Both manage shared amenities |
| noise_complaint | Both handle noise issues |

### LTR + HOA Only
| Capability | Why These Two |
|------------|---------------|
| long_term_resident | Both have long-term residents |
| annual_renewals | Both have annual cycles |
